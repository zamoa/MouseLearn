# 🐭 마우스 연습 게임

[![Deploy to GitHub Pages](https://github.com/zamoa/MouseLearn/actions/workflows/deploy.yml/badge.svg)](https://github.com/zamoa/MouseLearn/actions/workflows/deploy.yml)

6살 아이가 컴퓨터 마우스 사용법을 재미있게 배울 수 있는 웹 게임입니다.

**👉 [바로 플레이하기](https://zamoa.github.io/MouseLearn/)**

## 게임 구성

| 단계 | 연습 | 설명 |
|------|------|------|
| 1단계 | 👆 클릭 | 랜덤 위치에 나타나는 동물 이모지를 클릭 |
| 2단계 | 👆👆 더블클릭 | 알을 더블클릭하여 동물을 부화 |
| 3단계 | ✋ 드래그 | 과일/동물을 올바른 위치로 끌어다 놓기 |
| 4단계 | 🔤 알파벳 찾기 | 화면에 뿌려진 알파벳/영단어(APPLE, CAT 등) 중 안내 카드에 나온 것을 찾아 클릭 |
| 5단계 | 🇰🇷 한글 찾기 | 화면에 뿌려진 한글 자모/낱말(사과, 고양이 등) 중 안내 카드에 나온 것을 찾아 클릭 |
| 6단계 | 🍎 알파벳·그림 짝짓기 | "A로 시작하는 그림은?" / "APPLE의 그림은?" — 글자·단어에 맞는 그림을 찾아 클릭 |
| 7단계 | 🐱 한글·그림 짝짓기 | "ㄱ으로 시작하는 그림은?" / "사과의 그림은?" — 자음·낱말에 맞는 그림을 찾아 클릭 |
| 8단계 | 🃏 짝 맞추기 | 카드 12장을 더블클릭으로 뒤집어 그림 카드 ↔ 낱말 카드 짝 찾기 (영어·한글 혼합) |
| 9단계 | 🔨 두더지 잡기 | 글자를 든 두더지 중 안내 카드의 글자 두더지만 빠르게 클릭 |
| 10단계 | 🎣 낚시 | 안내 카드 낱말의 첫 글자(A / ㄱ) 물고기를 잡아 바구니로 드래그 |

4~7단계는 한 글자 라운드와 낱말 라운드가 번갈아 나옵니다. 낱말 라운드의 타일은 **그림으로 먼저 보이고, 더블클릭하면 낱말로 뒤집혀** 확인할 수 있습니다.

## 특징

- **난이도 선택** — 9단계 두더지·10단계 낚시는 시작 전 쉬움·보통·어려움으로 속도 조절 (선택은 기억됨)
- **단계 바로가기** — 상단 단계 번호를 누르면 원하는 단계로 바로 이동
- **큰 커스텀 커서** — 분홍 화살표(기본), 👆(호버), ✊(드래그) 3가지 모드
- **즉각적 피드백** — 파티클 효과, 효과음, 점수 표시
- **모바일 지원** — 터치 디바이스에서도 동작
- **외부 의존성 없음** — 단일 HTML 파일, 순수 HTML/CSS/JS

## 실행 방법

`index.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 빌드가 필요 없습니다.
