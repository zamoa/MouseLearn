# 🐭 마우스 연습 게임

[![Deploy to GitHub Pages](https://github.com/zamoa/MouseLearn/actions/workflows/deploy.yml/badge.svg)](https://github.com/zamoa/MouseLearn/actions/workflows/deploy.yml)

6살 아이가 컴퓨터 마우스 사용법을 재미있게 배울 수 있는 웹 게임입니다.

**👉 [바로 플레이하기](https://zamoa.github.io/MouseLearn/)**

## 게임 구성

| 단계 | 연습 | 설명 |
|------|------|------|
| 1단계 | 👆 클릭 | 랜덤 위치에 나타나는 동물 이모지를 클릭 |
| 2단계 | 👆👆 더블클릭 | 알을 더블클릭하여 동물을 부화 |
| 3단계 | ✋ 드래그 | 과일/동물을 올바른 위치로 끌어다 놓기 |

## 특징

- **큰 커스텀 커서** — 분홍 화살표(기본), 👆(호버), ✊(드래그) 3가지 모드
- **즉각적 피드백** — 파티클 효과, 효과음, 점수 표시
- **모바일 지원** — 터치 디바이스에서도 동작
- **외부 의존성 없음** — 단일 HTML 파일, 순수 HTML/CSS/JS

## 실행 방법

`index.html`을 브라우저에서 열면 바로 실행됩니다. 별도 설치나 빌드가 필요 없습니다.
